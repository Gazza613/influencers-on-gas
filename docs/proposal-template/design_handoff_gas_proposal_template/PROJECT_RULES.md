## New client proposals — locked-in template

For every new client proposal, START by copying `GAS Proposal Master Template.dc.html` (the approved Chilla v5 structure) to `<Client> Proposal.dc.html`, then adapt. Never rebuild from scratch.

Rules when adapting: recolour the whole palette to the client's CI (gradients + accents, done via find-replace on hex values); swap logos in assets/; ground every claim in the client's real research (no fabricated numbers, baselines "measured in week one"); journey is always paid ad → WhatsApp → PSI score → booked next step; pod names fixed: Researcher, Strategist, Audience, Creative, Channels, PSI, PSI Conversion Dashboard, Media on GAS; proof-of-concept length and page count may vary per deal; renumber footers sequentially after any page add/remove.
